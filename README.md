# Notification & Audit Services

A multi-service architecture demonstrating integration between a Project Service and a Notification/Audit Service, with comprehensive testing and documentation.

## Quick Start

```bash
npm install
npm run build
npm start
```

## Development

```bash
npm run dev          # Run with ts-node
npm run test         # Run tests with coverage
npm run lint         # Check code style
npm run type-check   # Type checking only
```

## Services

- **Project Service**: Core project management functionality
- **Notification Service**: Event-driven notifications and alerts
- **Audit Service**: Immutable event logging for compliance

See [ARCHITECTURE.md](./ARCHITECTURE.md) for design details.
